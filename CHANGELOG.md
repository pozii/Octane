# Changelog

Octane releases are cut from tags (`v<mod_version>-mc<mc_version>`) by CI —
see `.github/workflows/release.yml`. Per-release highlights live in the
auto-generated GitHub Release notes; the compatibility and benchmark matrix
lives in `docs/BENCHMARKS.md`.
